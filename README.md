Friends test
============

This is an implementation of the friends test (friends.test in R), formely known as best.friends and gene.friends .

The idea is: we have two sets of elements, and elements of the second (${C}$) interact with elements of the first (${T}$), 
and the interaction strength is described by a $|T|x|C|$ interaction matrix. The stronger is the interaction, the higher is the interaction matrix value. 
Here we propose a method that identifies the C elemetns that friends to particular elements of ${T}$.

To be a friend means to interact with a $t \in {T}$ element more strongly than with other elements of ${T}$
